# みんなの庭（初版）

2026-10-06追加。最終進化したキャラクターが集まる、シンプルなピクセルアートの庭。

## 遊び方

- 「みんなの庭」タブを開く。960×576pxの庭をスマホでは上下左右にスクロールできる。
- 最初からベンチ・お花の鉢・クッション・切り株テーブルを1個ずつ持っている。最終進化前でも配置できる。
- 持ち物から家具を選び、芝生のマスをタップして配置する。庭の家具を選んで移動・「しまう」で片付けられる。家具は消費せず、何度でも置き直せる。
- 最終進化した仲間は図鑑の育成記録から参加する。同種の仲間も別個体として残る。1画面20匹までで、仲間のページを切り替えられる。過去の記録は25件ずつ追加読込する。
- 仲間はカクカクと散歩し、家具のそばで♪やZzzのリアクションをする。タップすると育成時の思い出を見る。動きを減らす端末設定では静止する。
- 最初の最終進化以降、お手伝いが3回承認されるごとに仲間が家具を1個発見する。4種類から抽選し、重複も別の家具として配置できる。拾う家具は最大60個（初期4個と合わせ64個）。
- 家具発見は家族単位。次のタマゴを育て始めても続く。見送り・未承認・ごほうび交換・連続ボーナスは回数に含めない。導入前の承認分を遡って家具に換算しない。
- おためしモードでは「育った仲間を呼ぶ」で5匹を表示できる。おためしの記録は保存されない。本番にはこのボタンを表示しない。

## 保存・権限

- 家族ドキュメントの `gardenUnlocked`、`gardenChores`、`gardenInventory`、`gardenLastFind` は親だけが更新できる。家具獲得は申請承認・ポイント更新と同じトランザクション内で確定する。申請IDから抽選するため再試行で結果は変わらない。
- 配置は `families/{familyId}/garden/{itemId}` の `{kind,x,y}`。親と承認済みの子供だけが閲覧・操作できる。家族外・未参加・参加解除後のアクセスを拒否する。
- ルールは所持する家具と種類の一致、フィールド、整数座標・範囲・池の除外を検証する。子供に家族ドキュメントや所持品の書換権限は与えない。
- アプリは全所持品の配置を読んだトランザクションで配置し、同時操作による重なりを防ぐ。ルール自体は家具同士の重なりまでは検証しない。キャラクターの散歩位置は端末ごとの演出で、家具の位置は家族でリアルタイム同期する。
- 既存の最終進化済み育成を持つ家族は、親のアプリで図鑑を読み込んだときに家具発見を有効化する。育成記録・ポイント・既存の家具を削除しない。
- オフライン編集は非対応。保存エラー時は完了表示をせず、再操作できる。所持品・配置を本番でlocalStorageに代替保存しない。

## 検証

`npm test` に家具獲得・二重承認・交換との独立・配置制約・上限のテストを追加。`tests/rules.test.mjs` で家族内共有、子供の配置、未所持家具の拒否、不正座標・フィールド・家族外・参加解除後の拒否を確認する。
