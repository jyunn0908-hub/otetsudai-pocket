# お手伝い集計と連続ボーナス

2026-10-05の追加合意。親の承認済み履歴を使い、「きろく」に合計回数、今月の回数、お手伝いした日数、現在と最高の連続記録を表示する。既存の履歴も集計する。日付は日本時間の申請日を用い、承認が遅れても申請日の実績として扱う。同日複数回のお手伝いは回数には足すが、日数は1日分。

## ボーナス

- ごほうび交換用ポイントへ、1つの連続記録につき3日達成で10pt、7日達成でさらに30ptを各1回付与する。8日目以降は記録を伸ばせるが追加付与はない。
- 1日のお休みは連続を維持する。お休み自体は達成日数に含めない。2日続けて休んだら、次のお手伝いから新しい連続記録になる。
- 累計回数、最高記録、獲得済みのポイントは減らない。キャラクターの成長ポイントや進化条件にボーナスは影響しない。
- この版で新しく承認されたお手伝い履歴に `bonusEligible: true` を付ける。以前に承認済みの履歴はボーナスに遡及しない。そのため導入直後は「いまの連続記録」と「ボーナスチャレンジ」の日数が異なる場合がある。
- 承認・通常ポイント・ボーナス・履歴の保存は既存の同一Firestoreトランザクションで行う。子供は直接残高を書き換えられない。
- `type: bonus` の履歴に達成日と節目の日数を保存し、画面ではお手伝い履歴と区別する。ボーナス履歴をお手伝い回数に含めない。
- 遅れた承認で過去の連続記録がつながっても、その記録内で既に付与済みの節目は再付与しない。結合前の別々の記録で得たポイントは取り消さない。
- 端末引き継ぎでは既存処理が全履歴の子供IDを置換するため、回数・達成日・ボーナスの付与記録も保持される。

## 検証

`npm test` で集計、同日の重複、3日・7日、休みの境界、遅れた承認と記録の結合、既存履歴、再読み込み、交換、端末引き継ぎを検証する。Firestoreアクセス制御と保存先は変更しない。
